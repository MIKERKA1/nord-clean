# Nord Clean — демо-сайт клининговой компании

Портфолио-проект. Компания вымышленная, цены и контакты условные, форма заявки ничего не отправляет.

## Запуск

Сборка не нужна — это статический сайт без зависимостей.

```
cd nord-clean
python -m http.server 8080      # затем http://localhost:8080
```

Можно открыть `index.html` двойным кликом, но через локальный сервер надёжнее.

## Проверка расчёта цены

```
node price.test.js   # → price ok
```

## Где что менять

| Что | Где |
|---|---|
| Услуги, цены, допы, контакты, разброс ±% | `data.js` |
| Формула расчёта | `price.js` |
| Куда отправлять заявки | `data.js` → `formEndpoint` (POST JSON; `null` — демо-режим) |
| Тексты секций | `index.html` |
| Цвета, шрифты | `styles.css` → `:root` (светлая тема) и блок «Тёмная тема» в конце файла |

## Библиотеки

| Библиотека | Версия | Где используется |
|---|---|---|
| [anime.js](https://animejs.com) | 4.5.0 | Сцена с ковром: timeline «раскатка → пауза → чистка», кнопка «Почистить целиком», частицы пыли из-под насадки |
| [Motion](https://motion.dev) | 14.2.0 | появление карточек «До / После» (`inView` + stagger), смена панели услуги (spring без отскока), барабан цифр суммы в калькуляторе, подсказка-покачивание ручек, появление поля количества и экрана после отправки |

Обе подключены UMD-бандлами из `vendor/` (глобальные `anime` и `Motion`), сборщик не нужен. Обновить версии: `npm install`, затем `npm run vendor`.
Библиотеки не делят элементы: anime.js ведёт только объект состояния ковра и частицы пыли, Motion — элементы интерфейса.

## Устройство

- `index.html` — разметка и векторная графика (ковёр, ткань, плитка, «грязь») в SVG-спрайте.
- `app.js` — меню, сцена с ковром, сравнения до/после, услуги, калькулятор, форма.
- Ковёр — два акта, по мотивам идеи cleangomel.by (без копирования их графики и текста): `u` — ковёр раскатывается из рулона грязным, `p` — насадка экстрактора проходит по нему и оставляет чистый ворс с влажным следом. Шаги истории подсвечиваются под сценой.
- Управление ковром и сравнениями: только после нажатия (pointer capture, без реакции на наведение); у сравнений захват — за ручку; клавиатура — стрелки, Home, End; касание не блокирует вертикальную прокрутку.
- `prefers-reduced-motion`: без анимаций, ковёр развёрнут и наполовину очищен, секции видны сразу.

## Что не сделано / идеи на потом

- `og:image`, sitemap и robots.txt — когда будет домен.
- Браузерные e2e-тесты в репозитории: проверка проводилась разовым скриптом на playwright-core + установленном Edge (вне проекта).

## Проверки качества

- Анимации: аудит `/design-motion-principles` (взгляды Jakub + Jhey) и стандарт `review-animations` Эмиля Ковальски. Ковёр пишет стили прямо в элементы, рулон и насадка двигаются только через `transform`, hover-эффекты включены только при `(hover: hover) and (pointer: fine)`.
- Дизайн: `impeccable detect index.html styles.css`, 0 замечаний. Исключения с причинами лежат в `.impeccable/config.json`.
- Тексты: `/humanizer-ru`, чистота 96 → 98 из 100, длинных тире в видимом тексте нет (диапазоны вроде «3–4 часа» оставлены).
- Тёмная тема: по умолчанию следует системной настройке (`prefers-color-scheme`), кнопка солнце/луна в шапке фиксирует выбор в `localStorage`. Короткий скрипт в `<head>` применяет выбор до первой отрисовки, без вспышки светлой темы.
